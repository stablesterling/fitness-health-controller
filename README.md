# Fitness & Health Controller

A public, no-signup fitness and health tracking web app — single self-contained HTML file.

- Workout, water, sleep, weight/BMI, heart-rate logging with animated charts
- Multi-profile support (per-browser), goals, streaks, insights
- All data stays in the visitor's own browser (localStorage) — no backend, no accounts

Open `index.html` or visit the GitHub Pages site.
